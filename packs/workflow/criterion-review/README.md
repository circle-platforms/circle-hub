# 判据变更复核

本包只核验确认的形状、引用和非作者账号身份；接受或不接受由账号主人确认，模型只起草。声明必须显式绑定原始提交记录，不能用受理结果代替。每条待复核声明独立投影，接受和不接受都可以满足“已完成复核”的要求项。

`declaration` 是必填的被核验材料；可选多值 `evidence` 是期望角色，绑定声明所引的可读原片段。包检查不越过当前复核者的读权：缺原件时补绑，缺权限时由管理员补授权或由有权限的非作者复核，再重新开始。分享前驱不会分享原件。

只读前驱仅放宽开始运行的读门，不沿用租约、客户端键、修复预算或条目复用。独立性按 Hub 账号核验，作者包括声明运行及全部血缘的 runner（无 runner 时用 configurer）；会话和模型族不参与这一判断。请求的期限来自原运行提交期限，过期仍可回答；本次开始之后才接受的声明只进入以后修订。

请求回答只披露接受与否、理由、复核人和结果引用；作者不能借回答读取复核人的私有结果。源文件和历史结果始终不改写。

合成正例包括接受与不接受，反例包括缺少确认和错误来源。发布检查执行这些样例。真实数据和独立人工确认不在这些测试的证明范围内。
