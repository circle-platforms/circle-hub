# 类型化判据独立复核

只复核声明的判据类型、字面/次数/捕获关系是否忠实覆盖作者期望，不编写设备命令、不修改原期望，不签设备结果。

以原 case-compile 声明运行为 predecessor，declaration 绑定原提交 rec:，evidence 绑定原作者期望原件。确认实际前驱与原声明运行一致；由作者之外的账号逐项接受或拒绝，写理由和逐字 quote。没有证据保持未知，不勉强选择一种类型。

提交 review 的 code=accept/reject，location 原样取该条目位置，data.reason 写理由，quotes 逐字抄原 criterion.quote。把本复核的运行快照 rec: 和已受理结果 rec: 都交回主包；主包核实际前驱、独立性与声明全字段，不接受上传 JSON 自述。
