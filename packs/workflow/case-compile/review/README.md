# case-compile 的类型化判据复核阶段

本目录是同一编译工作的独立复核阶段发布单元，不在核心增加判据或设备语义。用现有 workflow 的只读前驱、按账号独立判断和原件引文机制；不修改 W10。发布时单独 stage 此目录并分配给复核者，主包的旧计划不依赖此阶段。

主包需要复核运行快照与已受理结果两份真实 Hub 记录，以核实际 predecessor 是否等于原声明运行，防止选择无关前驱取得独立标记。缺记录、拒绝判断、缺读权均不当成接受。测试只用合成来源。

复核者与作者不同账号时，由管理员按既有权限机制分享复核运行给作者，再绑定该运行完整快照及已受理结果的 `rec:`；不要求作者伪装成复核者，也不上传自述副本。
