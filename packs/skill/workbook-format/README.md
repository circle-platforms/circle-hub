# 工作簿格式通用技能包

本包按决定 72 独立发布，由管理员显式安装，不随 Hub 发布，不按用户分配。它解释 XLSX 工作簿与 SpreadsheetML 文件结构，不识别产品、不判断哪些单元格属于何种业务角色，不承担编译、评审或计划执行规则。

## 发布、安装与依赖

用 `node packs/skill/workbook-format/api.ts sign` 重签，`check` 检查；`stage <目录>` 导出仅含清单文件的发布目录。管理员以 `circle-hub pack publish <目录>` 发布，再 `circle-hub pack install workbook-format@1.0.1` 安装；`pack uninstall workbook-format` 停止新运行使用。发布新版本不会自动升级安装版本。技能包不赋予任何原件或产品知识的读取权限。

工作包在 pack.json 声明 `dependencies: [{"pack":"workbook-format"}]`，可附精确 `version`。管理员安装的版本必须满足声明，否则 start_run 在读取前拒绝，写出缺少的依赖和安装出口。新运行将可用的安装集合锁为 `skills: [{pack,version,digest}]`；结果锁与主张有效条件包括这些摘要。已锁运行按自己的摘要读取，后续升级、卸载不改历史。安装是全局授权记录绑定包摘要，非用户分配。

## 旧运行兼容

`src:<摘要>/xlsx@1/c/<工作表名>/<A1>` 与 `i/...` 地址不变。有 skills 锁的运行按该摘要复核。迁移前没有保存摘要的运行不能从当前安装版本补造历史：管理员首先以 `circle-hub skill bind-legacy xlsx@1 workbook-format@1.0.1` 追加迁移时点声明；已获授权的逐运行显式声明仍可用 `circle-hub pack bind-skills <运行> --skill workbook-format@1.0.1 --reason <理由>` 单独追加。绑定记录引用原运行记录与包发布记录，保留账号与理由；原运行和原结果不改，不能重绑。复核会披露“管理员事后声明”，不声称当时执行过该包。未绑定时说明缺失事实及补绑定出口。

## 迁移等价与验证

`testing/baseline` 保存迁移前核心 77e9de85 的七个文件的原始字节和 SHA 清单，只作测试数据，不进发布清单。测试在临时目录重建原模块，不能用搬迁后的实现充当基线。迁移测试枚举仓库相关夹具及合成工作簿，比较全部可读工作簿的模型、摘要与选择器。原有解析器向量逐项保留在包内测试。

## 按需取片段

fragments 的 JSON 估算超过 4 MiB 就不随解析输出，由 locate 按需给，一次最多 256 个。不超过就仍走急切路径。合成工作簿 20000 个单元格、文件 118353 字节，估算超过 4 MiB。一次沙箱测量：解析输出 2080616 字节，沙箱内 509 毫秒，fragments 未随解析输出。单元格地址 `c/` 与 `i/` 不变。

选择器由工作簿解析器按结构生成：工作表名和单元格地址唯一时使用 `c/`，名称有歧义时使用 `i/` 回退。急切输出和按需定位使用同一语法，不为唯一的单元格额外补位置别名；位置序号也不接受前导零。引文候选与解析器返回的单元格及定义名一致。
