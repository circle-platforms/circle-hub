# 脑图格式读取

提供 KityMinder 原文结构、规范选择器与片段。解析器不判断节点属于哪种工作角色；模块 case-structure 按树位置和声明字段读出用例、前置、动作和期望，工作流内嵌使用。由管理员安装；工作包声明依赖并在运行中锁定包摘要。格式不成立返回结构化解析失败，不猜测、不分类正文。

## 本地工具

两个工具都只读给定的文件、写一个新文件（不覆盖），不打印原文；路径都写工作目录内的相对路径。

- `node '<技能目录>/tools/parse-model.ts' --source '<原件>' --out '<模型文件>'`：用本包发布的解析器把完整原件解析成 `kityminder@1` 模型，带原件摘要。
- `node '<技能目录>/tools/locate-quotes.ts' --source '<原件>' --model '<模型文件>' --candidates '<候选>' --out '<结果>'`：候选写成 `[{"item":"<用例编号>","selector":"<节点>","text":"<显示原文>"}]`；结果逐条给出这段原文在原件里的字节跨度（`quotes`），一处、多处或零处都照实列出。原件经过字符替换时拒绝。用例归属由 Hub 在提交时核对。
