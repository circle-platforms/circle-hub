# XML 格式通用技能包

本包按决定 72 独立发布，由管理员显式安装，不随 Hub 发布，不按用户分配。它解释通用有序 XML 元素树与命令树结构，不识别产品、不判断哪些元素属于何种业务角色，不承担编译、评审或计划执行规则。

## 发布、安装与依赖

用 `node packs/skill/xml-format/api.ts sign` 重签，`check` 检查；`stage <目录>` 导出仅含清单文件的发布目录。管理员以 `circle-hub pack publish <目录>` 发布，再 `circle-hub pack install xml-format@1.0.1` 安装；`pack uninstall xml-format` 停止新运行使用。发布新版本不会自动升级安装版本。技能包不赋予任何原件或产品知识的读取权限。

工作包在 pack.json 声明 `dependencies: [{"pack":"xml-format"}]`，可附精确 `version`。管理员安装的版本必须满足声明，否则 start_run 在读取前拒绝，写出缺少的依赖和安装出口。新运行将可用的安装集合锁为 `skills: [{pack,version,digest}]`；结果锁与主张有效条件包括这些摘要。已锁运行按自己的摘要读取，后续升级、卸载不改历史。安装是全局授权记录绑定包摘要，非用户分配。

## 旧运行兼容

`src:<摘要>/xml@1/x/<路径>` 与 `i/...` 地址不变。有 skills 锁的运行按该摘要复核。迁移前没有保存摘要的运行不能从当前安装版本补造历史：管理员首先以 `circle-hub skill bind-legacy xml@1 xml-format@1.0.1` 追加迁移时点声明；已获授权的逐运行显式声明仍可用 `circle-hub pack bind-skills <运行> --skill xml-format@1.0.1 --reason <理由>` 单独追加。绑定记录引用原运行记录与包发布记录，保留账号与理由；原运行和原结果不改，不能重绑。复核会披露“管理员事后声明”，不声称当时执行过该包。未绑定时说明缺失事实及补绑定出口。

## 迁移等价与验证

`testing/baseline` 保存迁移前核心 78b3c5b5 的六个文件的原始字节和 SHA 清单，只作测试数据，不进发布清单。测试在临时目录重建原模块，不能用搬迁后的实现充当基线。迁移测试枚举仓库全部相关夹具及合成 XML 文档，比较全部可读 XML 的模型、摘要与选择器。原有解析器向量逐项保留在包内测试。

## 按需取片段

解析时按文档本身估算 fragments 的 JSON。逐条累计，不超过 4 MiB 就随解析输出（急切路径，和以前一样）；超过就不输出 fragments，由 skill.json 的 locate 按调用方给的选择器现算，一次最多 256 个。同样的字节永远走同一条路，估算不用时钟。quotation 仍随解析输出。

XML 的新包产出可将相邻路径按共同前缀编码，引文的选择器可引用清单下标，流中片段可用范围表达。Hub 在 hydrate 时还原原有清单和逐字单元；旧包完整字符串数组及引文单元仍可读，引用语法不变。单元的属性文字没有流中范围，仍随单元原样返回。

资源回归测试使用三种没有填充注释的合成 XML：约 2.10 MB 的深层属性树（2.2 万元素、约 11 万属性）、约 2.10 MB 的属性丰富树（约 2.8 万元素），以及约 2.13 MB 的 40 层长文本树（约 2 万元素）。测试每种形状调用真实包沙箱，执行 parse、hydrate、操作期缓存和一次含两个选择器的 prefetch；它断言解析输出不超过 24 MiB、沙箱解析调用小于 3 秒、parse 加 hydrate 小于 5 秒、完整流程小于 10 秒，采样到的沙箱子进程 RSS 小于 416 MiB、测试进程与子进程 RSS 合计小于 1152 MiB。RSS 每 25ms 采样一次，可能漏掉短峰，并非任意输入或整个服务的物理内存保证。测量输出时额外序列化一次 JSON，计入耗时和内存。

一次 macOS 合成测量中，三种形状的输出分别为 20,050,017、18,676,564、12,185,282 字节；沙箱 RSS 采样峰分别为 325,910,528、336,543,744、169,787,392 字节；完整流程分别为 1495、1131、712 毫秒。三项在同一测试进程顺序执行，父子 RSS 合计采样峰分别为 741,130,240、951,697,408、938,934,272 字节，后两项可能包含 V8 留存的前一项内存。结果只证明这些合成形状，不能外推到真实原件。

运行 `node --test --test-concurrency=2 packs/skill/xml-format/functions/resource.test.ts` 复测。测试允许没有 OS 隔离的合成环境执行，因此设 `requireOsIsolation: false`；macOS 可用 `sandbox-exec` 时包装器仍启用它，测试记录 `osIsolation` 以便确认本机结果。旧地址 `x/` 与 `i/` 不变。
