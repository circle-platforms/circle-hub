# Lumen API 2.1.0 接口参考

合成的接口说明。引用一个接口时写 `<方法> <路径> <参数取值...>`，参数按下表的顺序。

## GET /v1/pools

列出池，按名称排序。

| 参数 | 类型 | 取值 |
| --- | --- | --- |
| limit | 整数 | 1-100，可选 |

## POST /v1/pools

创建一个池。

| 参数 | 类型 | 取值 |
| --- | --- | --- |
| name | 字符串 | 1-32 |
| mode | 枚举 | rr、lc、hash，可选 |

## DELETE /v1/pools/{id}

删除一个池；池里还有成员时返回 409。

| 参数 | 类型 | 取值 |
| --- | --- | --- |
| force | 枚举 | true、false，可选 |

## GET /v1/health

返回服务状态，没有参数。

## 附录：错误码

409 表示冲突。
