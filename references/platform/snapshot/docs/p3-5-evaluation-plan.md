# P3-5 真实模型 L4 评测计划（冻结版 v1）

- 日期：2026-10-10
- 步骤：P3-5（真实模型 L4 评测）
- 前置：DEC-P3-04 已定案（ADR 0026）——阿里云百炼 Token Plan Anthropic 兼容端点，模型 `qwen3.8-flash`
- 阈值依据：ADR 0013（程序可判项 100%；与人工标注一致率初始 ≥90%；弃权一等公民；阈值变更须新 ADR 附校准数据）
- 状态：**本计划冻结待用户确认后运行**；运行产出记入 `docs/p3-5-l4-record.md`

## 1. 评测对象与实现

新增真实 assessor 实现（`packages/llm-assessor`），实现 P2 冻结的同一 `Assessor` 接口，经保险库连接器调用 Messages API。每条 AssessmentRecord 记 methodId `llm-assessor`、methodVersion 为运行器版本、modelId `qwen3.8-flash`（ADR 0013/0026）。脚本化 assessor 的既有校准结果不与本轮混合统计。

提示词集冻结为 `p3-5-prompts-v1`（随运行器代码入仓）：系统提示固定要求只依据所给证据作答、只能输出约定 JSON（结论枚举 + 依据摘要 + 未知项）；证据与主张由运行器按冻结样本组装。输出解析失败记为一条 `abstained` 并附原始输出哈希，不改写、不重试语义（见 §4 重试规则）。

## 2. 评测集（全部为 P1-4 冻结样本，不新增、不改动）

**V01（主）**：SMP-V01-01..04 的问题集。每题由链的程序侧按既有规则选出证据集（与 P2-3 相同的程序路径），真实 assessor 对（主张， 证据）作语义判断；与冻结期望结论比对一致率。冲突题（V01-02）的期望是呈现冲突——assessor 须对任一单值主张给出非 supports 的判断且整链结论为冲突呈现，方记一致。

**V04（主）**：SMP-V04-01 基线集（3 例）与 SMP-V04-02 缺陷集。模型按冻结的四维分类法（越权未校验/异常分支缺失/凭据明文记录/内部矛盾）输出结构化发现（用例、类型、严重度、依据），与冻结期望 D-01..D-04 按（用例， 类型， 严重度）比对：期望发现召回、额外发现数、基线误报数分别计量。UC-04R 全文为测试侧按样本说明构造的夹具（P2-4 已披露），本轮沿用同一夹具并继续标注此口径。

**V03 视觉试点（辅，无门槛判定）**：先以 1 张截图做图像输入探针（端点是否接受 image 块）。接受才继续：以 P3-3 浏览器 worker 在本地测试站截取四种状态画面（空白/凭据错误/锁定/MFA 等待），请模型只做状态分类，与页面 `data-state` 真值比对，描述性报告准确率；不接受则试点记为「通道不支持图像输入」并关闭，不影响 V01/V04 结论。此试点不替代 OPEN-07 的真实站点视觉判定。

## 3. 冻结参数

| 项 | 值 |

| 模型 | `qwen3.8-flash`（端点与凭证见 ADR 0026） |

| 提示词集 | `p3-5-prompts-v1` |
| 每次调用超时 | 300 秒；耗时与 usage 逐条记录 |
| 重试 | 仅传输/5xx 错误可重试，上限 2 次且保留每次尝试记录；解析失败与语义结果不重试 |

## 4. 预算上限（冻结，运行器硬停）

全轮上限：**120 次 API 调用、总 token 1,500,000**（含探针与重试）。参考量级：V01 约 8–16 次、V04 约 10–20 次、V03 ≤ 8 次、探针 ≤ 4 次，其余为重试与一次复核余量。任一上限先到即停，停时状态按 partial 记录已完成部分，不 extrapolate。Token Plan 的 Credits 换算以控制台为准，本计划只控制调用与 token 量。

## 5. 判定与记录

- 程序可判项（证据选择、绑定校验、状态呈现等程序侧断言）须 100%——与 P2-3 同口径复核。
- 语义一致率（V01 结论一致、V04 期望发现匹配）按 ADR 0013 以 ≥90% 为初始门槛逐链判定；未达标如实记 fail，不调阈值、不挑样本。
- 棄权（abstained）单独计数并列出原因分布，不算作一致也不算作错误之外的隐藏项。
- 原始响应只保存在运行工作区（不入仓）；入仓记录含逐项结果、聚合指标、usage 与耗时汇总、失败与弃权清单、提示词集与参数快照。
- 本轮结论只对该模型与该参数集成立；脚本化 assessor 的 100% 校准不得与本轮结果并列引用为同一口径。
