# P2 隔离纵切规划

日期：2026-10-10。

状态：**已收口（2026-10-10，用户裁定门禁通过，ADR 0015）。OPEN-02/03/04 已由 ADR 0011–0013 定案，本计划按其执行完毕。** P2 的边界不变：全部纵切在隔离环境内（内存/本地存储、夹具、本地测试站），**不连接真实设备、不操作真实站点、不部署、不引入真实凭据与真实业务数据**。

## 1. 目标

把五条链逐条做成端到端可运行的最小纵切（L2），每条链以其冻结样本为验收输入、以完成清单构成 V1 为交付判据。先无副作用链（V05、V01、V04），后模拟副作用链（V02 夹具、V03 测试站）。

## 2. 包结构（新增，monorepo 同级）

| 包 | 职责 |
| --- | --- |
| `packages/platform` | C/D 最小核心：任务服务（阶段、待输入、完成清单判定）、操作服务（六调用、租约+fencing、幂等存储，按 ADR 0011 参数）、证据/产物登记。内存实现 + 可替换存储接口 |
| `packages/knowledge` | B 最小实现：来源修订与快照存储（按 (tenant, scope) 分区，ADR 0012）、引用解析与撤回检查 |
| `packages/assessor` | 语义判断接口 + scripted assessor（ADR 0013）；校准运行器与一致率报告 |
| `packages/chain-v05` | 脑图编译器：content.json/主题树 → IR → .xlsx（Excel 输出契约 V1），逐格比对 SMP-V05-02 |
| `packages/chain-v01` | 知识问答纵切：快照绑定、检索、引用、支持判断、完成清单判定 |
| `packages/chain-v04` | 用例评审纵切：输入哈希绑定、维度判断、签字流 |
| `packages/apv-fixture` | SMP-V02-01 夹具实现（示意命令集、状态机、5 个注入点）+ V02 操作纵切 |
| `packages/test-site` | SMP-V03-01 本地测试站实现（登录/MFA/锁定/会话）+ V03 操作纵切（本地浏览器自动化或 HTTP 流程级，先定于 P2-6 启动时） |

既有包不动：`packages/contracts`（仅按 v1.2 清单增补错误码）、`packages/server-stub`（保留为对拍参照）。

## 4. 不做（P2 红线）

- 不接真实 APV/真实站点（OPEN-06/07 仍在 P4）；不引入真实模型 API 密钥（assessor 真实实现另行 ADR）；不做多租户实际隔离部署（只按 ADR 0012 预留维度）；不做 UI。

## 5. 与延后登记的对应

OPEN-02/03/04 由 ADR 0011–0013 在 P2 启动时定案；XMind 版本范围、MCP 版本实测、真实样本仍按 P1 收口登记的去向推进，不被 P2 顺带宣称解决。
