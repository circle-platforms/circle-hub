## 3. V04 结果：未达标（如实记录）

基线集（SMP-V04-01，3 例）：模型发现 **0 条**、高严重度 **0 条**——无误报，与冻结设计一致。

期望缺陷按冻结口径（用例 + 类型 + 严重度）命中 **3/4 = 75%**，低于 ADR 0013 的 ≥90% 门槛——**本链语义门槛本轮未达标**，不调低门槛、不改标注、不挑样本。

| 缺陷 | 用例 | 期望（类型 / 严重度） | 模型 | 命中 |
|---|---|---|---|---|
| D-01 | UC-04 | 越权未校验 / high | 越权未校验 / high | ✓ |
| D-02 | UC-05 | 异常分支缺失 / medium | 异常分支缺失 / medium | ✓ |
| D-03 | UC-05 | 凭据明文记录 / medium | 凭据明文记录 / **high** | ✗（严重度分歧） |
| D-04 | UC-04R | 内部矛盾 / low | 内部矛盾 / low | ✓ |

D-03 的解剖：模型在正确的用例上检出了正确的缺陷类型——把「新口令原文写入日志」判为 high，而冻结标注为 medium。这是**严重度标定分歧**，不是漏检。按类型口径（用例+类型）计，期望缺陷检出为 4/4；但冻结门槛的口径含严重度，故结论仍为未达标（此段仅为归因说明，不改变判定）。

修订用例 UC-04R：D-04 命中、且已修复的 D-01 不再报告，两项均符合期望（UC-04R 全文为 P2-4 起沿用的测试夹具，按样本 revisionSet 说明构造、非样本原文，口径不变）。

额外发现 2 条（均在 UC-05）：① 越权未校验 / high——模型认为重置口令仅凭账号与新口令、无任何身份/归属校验，可重置他人账号口令；冻结标注未登记此项，但从文本看是言之有据的读法。② 凭据明文记录 / high——即 D-03 的同类型发现被计为额外，是因其严重度与标注不符、未计入命中。额外发现按冻结规则如实计数与披露，不据此改判。

样本量提醒：期望缺陷共 4 条，一条分歧即 25 个百分点——75% 这个数字的粒度很粗。这本身是冻结集规模的事实，扩大标注集属于后续议题，不在本轮追补。

## 4. V03 视觉试点：描述性结果（无门槛）

图像探针：端点**接受** image 输入并正常返回，试点成立。本地测试站四种状态由真实浏览器截取（P3-3 口径），页面 `data-state` 为真值：

| 状态 | 页面真值 | 模型分类 | 对 |
|---|---|---|---|
| 空白 | login | blank | ✓ |
| 凭据错误 | login-error | credential-error | ✓ |
| MFA 等待 | mfa-waiting | **blank** | ✗ |
| 锁定 | locked | locked | ✓ |

准确率 3/4。MFA 等待页被判为空白表单——该页视觉上同为一个带输入框的表单页，是本试点的真实弱点记录。此试点不替代 OPEN-07 的真实站点视觉判定（P4）。

## 5. 结论与口径

- **L4（本轮范围）**：V01 通过（一致率 100%、程序项 100%）；V04 未达标（严格一致率 75%，归因于 D-03 严重度标定分歧）；V03 试点描述性 3/4。L4 不得整体表述为「通过」。
- 本轮结论只对（qwen3.8-flash、`p3-5-prompts-v1`、temperature 0、单遍）成立；脚本版/规则版的既有校准结果（P2-3/P2-4）与本轮不同口径，不得并列引用。
- 后续候选议题（不在本轮处理）：D-03 的严重度标注由谁复核——若认为标注应改为 high，须走样本修订与 ADR 0013 的阈值/标定变更程序；严重度标定指引是否写入提示词集 v2 亦然。两者都意味着新一轮评测，不在本轮内追改。
- 其余登记不变：真实站点/设备、OPEN-06/07 仍待 P4 单独授权。
