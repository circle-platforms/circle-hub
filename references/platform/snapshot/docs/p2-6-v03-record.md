# P2-6 完成记录：本地测试站与 V03 操作纵切

日期：2026-10-10。本记录是 P2 隔离纵切规划 P2-6 的出口证据。执行环境：助手自有计算机本地，测试站仅监听 127.0.0.1，账号与口令为虚构测试夹具，**未操作任何真实站点、未使用任何真实凭据**；真实 Web 目标与视觉模型属 OPEN-07（P4）。

## 1. 交付内容与一处开工决策

`packages/test-site`：

- `TestSite`：按 SMP-V03-01 实现的真实 HTTP 测试站——登录页/ MFA 页/控制台/锁定页与 `data-state` 状态标记、失败计数与 5 次失败锁定 15 分钟、MFA 60 秒窗口与 3 次错误作废、会话建立/登出/失效，站点时钟可快进，MFA 码只经站点侧模拟器带外可达。
- `WebLoginDriver`：V03 操作驱动——页面结果分类（logged-in / awaiting-mfa / credential-error / locked / mfa-timeout / mfa-failed / session-expired / target-unreachable）；口令与 MFA 码只经平台敏感待输入通道（decisionType credential/mfa + sensitiveChannel）进入，驱动不以普通参数接收、不保存凭据。
- `runAllScenarios`：SMP-V03-02 四场景的可执行脚本与逐条期望断言。

开工决策（规划留待 P2-6 启动时定）：纵切采用 **HTTP 流程级**而非浏览器自动化。理由：四场景的期望全部是流程/状态断言，可用站点的确定性状态标记在 HTTP 层判读；规格第 3 节的视觉状态判读依赖视觉模型（OPEN-07 未定），不在本步冒充。页面表单以 JSON 提交建模、状态以 `data-state` 标记判读，截图采集按规格留待视觉链阶段补入样本。

## 2. 场景实测（执行时验证）

| 场景 | 期望断言 | 结果 |
| --- | --- | --- |
| web-s1 错误口令 | 3 条（分类为凭据错误、计数递增、不误报成功） | 3/3 |
| web-s2 锁定 | 4 条（第 5 次进入 locked、锁定中正确口令仍 locked、与凭据错误可区分） | 4/4 |
| web-s3 MFA 超时 | 6 条（分类 mfa-timeout 非码错误、会话作废、迟到响应按过期被拒、任务 cancelled 收束） | 6/6 |
| web-s4 会话残留 | 4 条（旧 cookie 被重定向回登录、结论会话已失效、清理丢弃旧 cookie） | 4/4 |

另测：完整 MFA 登录成功且**平台留存记录（任务记录 + 全部结果）经扫描不含口令与 MFA 码原文**，两类待输入均经 `requiresSensitiveChannel` 断言为敏感通道；MFA 码错一次分类 mfa-failed 且会话可恢复后登录成功。test-site 测试合计 3/3。

## 3. 边界

- 测试站为类别行为模拟，不含任何真实产品的页面结构、商标或口令策略细节（规格第 4 节）。
- “凭据不落记录”的断言范围是本进程内的平台记录与驱动结果（任务/登记/结果对象序列化扫描）；浏览器/网络层面的凭据保护不在本步声称范围。
