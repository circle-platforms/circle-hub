# ADR 0023：本地沙盒研究的授权范围

日期：2026-10-10。状态：用户明确授权本地研究与实验，产品实现选型仍需依据研究结果讨论。

用户要求自己搭建本地沙盒，对能取得的项目看源码，对闭源部分看文档，重点研究成熟方案的精髓和我们的需求；同时强调复杂网络环境中的 debug 和分析是平台的意义之一。

本轮允许在隔离工作树与独立运行目录内取得公开源码、固定版本，安装仅供研究的依赖，运行本地合成的 TCP/HTTP/SSH/浏览器以及故障实验，保存脱敏研究记录和可重复脚本。自身研究脚本使用 TypeScript，上游第三方源码保留原语言并在独立目录研究，不进入生产实现。

本轮不连接真实设备或生产站点，不使用真实 Circle 数据，不读取真实设备凭据，不调用付费或外部真实模型，不改主机路由、DNS、VPN 和已有环境。本地回环实验只能证明其协议/进程/故障范围，不能宣称操作系统网络隔离、真机兼容或真实模型质量已经通过。

保留 ADR 0005 的历史范围。本授权修改的是本轮研究方式，不自动启动平台生产实现或部署。源码、文档观察、实际操作、验证结果和仍缺的证据分别记录。
