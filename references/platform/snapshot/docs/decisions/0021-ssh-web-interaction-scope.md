# ADR 0021：设备交互范围修订

日期：2026-10-10。状态：**用户明确的范围修改**；用户交互方法与对象通信的具体实现仍在讨论。

## 决定与修订范围

1. 设备管理通道以 SSH 与 Web 为当前设计范围。
2. 按用户“直接删除 console 部分”的要求，删除设备控制台/串口的连接、端口管理、显示和验收方案，取消此前的延期条目；不作为当前开发或后续门禁的待办。
3. Web 全过程实时可见、Otty 并排/普通终端打开 Chrome 的要求继续有效；SSH 的职责以[责任计划](../ssh-responsibility-plan-v1.md)为准。
4. 继续讨论用户交互与 A–E 对象通信；只写设计和计划并发布 GitHub，不授权业务实现、依赖安装或设备/浏览器实验。

本次同步修改入口、职责/显示计划、议程、讨论摘要和验证方案。此前相关方案的历史版本保存在 Git；静态来源盘点仍是指定旧项目的观察记录，不成为当前能力或待办声明。设备序列号、Web 页面的控制台和程序日志等同名内容不是本次删除对象。

本修订同步替代 ADR 0014 后续范围说明和 [ADR 0019](0019-visibility-parallel-track.md) 中原延期条目；不改变 P3 已确认的实施步骤和可见性独立验收边界。

讨论稿见[用户交互与对象通信 V1](../user-interaction-and-object-communication-v1.md)。本 ADR 不接受该讨论稿中的候选字段、服务布局、交接和传输选型为冻结接口。
