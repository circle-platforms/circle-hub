# ADR 0010：InfoSec 全产品线与负载均衡抽象基础

日期：2026-10-10。状态：用户明确的定位澄清；本次只修正文档。

## 背景与纠正

用户指出 README 中“尤其负载均衡产品”的描述容易将平台定位收窄。既有负载均衡/APV 工程是建立抽象的基础，InfoSec 有多条产品线，平台需要覆盖各产品的完整生命周期。

本决定澄清 [ADR 0001](0001-project-direction.md) 的产品范围及 README、vision 和 agent 指引中的相关描述，替代“重点面向负载均衡”作为平台范围的表述。

## 决定

1. 平台面向 InfoSec 全产品线，覆盖产品知识、操作、研发、测试、发布与维护。
2. 以负载均衡工程实践建立和验证首批通用抽象；APV 保留为初始设备场景，不据此限定平台产品范围。
3. A–E 职责与共同契约面向跨产品线复用。各产品的知识模型、命令、执行通道、资源语义和判据通过 B/E 模型、能力包及 D 适配器表达，不把负载均衡对象写成所有产品的必需模型。
4. 兼容性与效果按产品线、型号、版本和环境分别验证。APV 或模拟环境通过不证明其他产品线已受支持。

## 对已有工作的影响

五类对象、可替换 harness、全 TS 新建和现有五条基础验证链继续有效。本次不修改既有契约、schema、样本或代码，也不新增实施/部署范围。其他产品线的具体能力和验收样本后续逐项确定。
