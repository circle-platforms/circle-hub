# ADR 0019：操作可见性的并轨方式（DEC-P3-05）

日期：2026-10-10。状态：**已定案（用户确认）**。

## 决定

ADR 0014（操作全过程可见与两种入口布局）与 `docs/operator-visibility-plan-v1.md` 作为**并行需求轨道**推进，与 P3 的关系只包含两项接口工作：

1. A 侧会话关联/显示契约议题随 P3-4 的 harness 薄适配一并讨论（显示不改变 C/D/E 权威边界）；
2. D 浏览器 worker 的真实画面产出并入 ADR 0020 的 Playwright 评估范围。

可见性计划自身的验收提案（同会话/连续显示/控制交接等）按其计划推进与判定，**不并入 P3 门禁宣称**；P3 的任何通过结论不构成可见性已实现的证据。设备交互范围按后续 [ADR 0021](0021-ssh-web-interaction-scope.md) 为 SSH 与 Web，SSH 责任按其专门计划推进。

## 影响

P3 规划与收口评审引用可见性时只引用本 ADR 的两项接口工作；可见性轨道的新决定不自动改写 P3 范围，反之亦然。
