# ADR 0011：幂等窗口与租约参数基线（OPEN-02 定案）

日期：2026-10-10。状态：**已定案（用户于 2026-10-10 按建议确认）。**

## 决定（建议值，P2 基线参数，可调但改动须记录）

### 幂等

1. 去重键作用域 = `(principalId, 操作类型, idempotencyKey)`；判定重复时同时比对请求规范哈希：同键同哈希 → 返回原操作与当前状态，不重复执行；同键不同哈希 → 冲突拒绝（拟在契约 v1.2 增补错误码 `IDEMPOTENCY_MISMATCH`，类别 conflict-stale；增补前暂用 `DECISION_CONFLICT` 并在 P2-1 落码时一并升版）。
2. 在线去重窗口 **24 小时**；终局结果保留 **7 天**供 result 查询；超过窗口后同键按新请求处理（风险在文档中明示，调用方不得依赖超窗去重）。
3. 窗口与保留期是部署参数，不是协议常量；收紧/放宽走配置变更记录，不改契约。

### 租约与 fencing

4. 租约默认 TTL **60 秒**，持有方每 **20 秒**心跳续约；fencing token 按资源单调递增（FZ-07 已冻），过期或 fencing 落后的写入一律拒绝（`FENCING_STALE` / `LEASE_EXPIRED`）。
5. 租约到期处置按操作类型分流：只读操作可重新排队；**有副作用的操作到期即进 `unknown` 并走对账**，不自动重派（防双执行）。
6. 单次操作可续约总时长上限 = 操作自身截止时限（由任务绑定给出）；无截止时限的有副作用操作不予准入。

## 理由

- 数值取“够用的保守值”：60/20 秒是常见心跳配比，能把失联检出压在约一分钟内；24 小时覆盖人为重试与跨时区重提，7 天覆盖审计追溯的短窗口。没有真实负载数据前不假装精算，全部做成可调参数并要求 P2 用故障注入实测到期行为（R02）后再评估调整。

## 影响

- P2-1 的平台核心按本参数实现幂等存储与租约服务，并以注入测试验证第 5 条分流。
- 契约增补项（`IDEMPOTENCY_MISMATCH`）列入 P2-1 的 v1.2 升版清单。
