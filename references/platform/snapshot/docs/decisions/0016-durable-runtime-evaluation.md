# ADR 0016：C 持久运行选型评估顺序（DEC-P3-01）

日期：2026-10-10。状态：**已定案（用户确认）**。

## 决定

C 的持久运行选型按 `docs/cde-implementation-discussion-v1.md` 第 8 节执行：**优先评估 Temporal TS**，以讨论稿第 7 节的 C-T03（事务提交前后杀进程/中继/runner、重复与乱序唤醒、等待人工时重启）与 C-T04（流程代码升级与旧任务恢复）为对比样本，与替代路线（PostgreSQL 任务表 + TS worker）同场比较恢复正确性、重复作用、升级成本与运维开销。

本 ADR 定案的是**评估顺序与判据**，不是预先采用 Temporal。采用与否在 P3-2 评估跑完后另行 ADR 定案。评估期间两条路线都不得直写对方状态：Temporal history 只管定时器/调度/重放，C 的事务记录管输入、身份、人工决定与交付（讨论稿 3.3 的权威划分）。

## 影响

P3-1 先落事务受理与业务存储（ADR 0017），P3-2 再做选型对比；C-T03/C-T04 的回执是选型 ADR 的必需附件。
