# ADR 0013：语义判断的形态与质量门槛（OPEN-04 定案）

日期：2026-10-10。状态：**已定案（用户于 2026-10-10 按建议确认）。**

## 决定

1. **形态：可替换能力，不绑模型**。语义判断（Assessment）经统一接口调用，模型只是接口后的一种实现；每次判断必须记录方法标识与版本、模型确切标识（FZ-08 已冻）。P2 默认实现为 **scripted assessor**（按冻结样本的期望规则产生确定性判断，供管线与回归使用）；真实模型接入是同接口的可选实现，未接入前不构成任何链的阻塞，但也不得用 scripted 结果冒充模型质量结论。
2. **不设全局置信度阈值**。`confidence` 只作参考字段，永远不单独充当交付门禁（VER 原则）。交付与否由完成清单（程序核验 + 判断存在性 + 人工签字）决定。
3. **质量门槛按链、以冻结样本校准**：V01/V04 在 P2 必须跑校准集并报告与人工标注的一致率；**初始门槛：冻结样本集上一致率 ≥ 90%**，且程序可判部分（引用可解析、引用未撤回、绑定一致）必须 100%。未达门槛的链只能以“判断不可用/需人工复核”形态交付，不带病 delivered。门槛数值的调整需新 ADR 并附校准数据。
4. **弃权一等公民**：证据不足时必须 abstain / insufficient-evidence（FZ-08 已含），弃权不算失败，但必须在产物中如实呈现。
5. **人工优先**：人工 override 覆盖任何语义判断且留痕（FZ-08 已含）；评审类链（V04）的最终结论以评审人签字为准（完成清单 v04-signoff）。

## 理由

- 现在没有真实模型的校准数据，写死某个置信度数字是假精确；改为“接口先行 + 样本校准 + 一致率门槛”，门槛落在可测的人工一致性上，随 P2 实测收紧或放宽都有据可依。
- scripted assessor 让管线、清单与对拍在没有模型时也能全量跑通，模型质量与管线正确性分开验收（承接双轨原则）。

## 影响

- P2 的 V01/V04 纵切自带校准运行与一致率报告；报告模板在 P2-3/P2-4 落定。
- 真实模型选型不在本 ADR 范围：接入时以新 ADR 记录模型、版本与校准结果。
