# ADR 0017：业务持久存储基线（DEC-P3-02）

日期：2026-10-10。状态：**已定案（用户确认）**。

## 决定

C 的业务记录（任务、输入/计划修订、待决定、幂等、outbox、完成核验）与 B 的存储统一以 **PostgreSQL** 为持久基线，与 ADR 0003（知识基线 PostgreSQL + 对象存储）保持一致。P3 阶段使用本地隔离实例；受理语义为：任务、幂等记录与唤醒记录在同一事务提交成功后才返回 accepted（讨论稿 3.4），内存参考实现不满足该保证、仅保留为测试参照。

制品对象存储在 P3 以本地文件实现承载，接口位置按 S3 兼容形态预留；本 ADR 不定案对象存储产品。不采用 SQLite 作为持久轨道，避免与 ADR 0003 基线分叉出第二套事务语义。

## 影响

P3-1 的存储接入与 C-T01/C-T02/C-T03 均以 PostgreSQL 实例为环境前提；连接信息只经环境注入，不入仓。
