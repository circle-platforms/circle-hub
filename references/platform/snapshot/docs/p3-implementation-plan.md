# P3 规划：真实 harness 接入、持久化与语义质量

日期：2026-10-10。

状态：**已定案落档（2026-10-10，用户确认）。DEC-P3-01/02/03/05/06 已由 ADR 0016–0020 定案；DEC-P3-04 已由 ADR 0026 定案（2026-10-10，用户提供阿里云百炼 Token Plan 通道），P3-5 评测计划已冻结待运行确认。** 依据：验证矩阵第 5 节 P3 行（目标/进入条件/退出条件）、`docs/cde-implementation-discussion-v1.md` 第 7/8 节（验证样本与待决议题）、P2 收口评审（`docs/p2-closing-review.md`）第 3 节延后登记、ADR 0014（操作可见性，用户已确认需求）。新 ADR 自 **0016** 起编号（0014 已由可见性决策占用，0015 为 P2 收口）。

## 1. 目标

P3 把 P2 的隔离纵切推进到两个真实维度：**真实 harness**（Circle/Pi/OpenCode 固定版本薄适配、能力协商与降级标注、R06 接管序列，L3）与**真实持久运行**（C 的事务受理、崩溃恢复与选型定案；D 的真实进程级故障核对），并在模型选型定案后做**真实模型语义质量评测**（L4，V01/V04 为主）。真实设备与真实产品 Web 仍属 P4，不在本阶段。

## 4. 不做（P3 红线）

- 不接真实 APV/真实产品 Web（OPEN-06/07 仍在 P4，单独授权）；不做初始化/升级/破坏性设备操作与产品发布/回退（EFF-02 单独成链）。
- 不部署到本地隔离评估环境之外；模型密钥不入仓、不进日志与回执。
- 不以官方 MCP 测试客户端或单个 harness 的通过推及三 harness 兼容（矩阵第 6 节）。
- Console Server/串口接入按 ADR 0014 后续修订延期；SSH 责任按其专门计划推进，不并入 P3 门禁。
- 旧项目仍仅作需求/数据/行为参考，不复制、包装或调用其代码（常设约束）。

## 5. 与延后登记的对应

P2 收口登记中归 P3 的三项在本规划落实：MCP 协商版本实测（P3-4）、R01/R02 真实进程实验与持久化（P3-1/2/3，其中 R01 的 L3 复核在 P3-4）、平台并发语义（C-T02 与 D-T02 覆盖核心冲突面）。XMind 版本范围仍待真实样本；真实样本引入仍为 0，L4 评测使用冻结标注集与后续新增标注集（按 samples 规则登记）。
