# @infosec/apv-fixture

按 SMP-V02-01 规格实现的 APV 协议夹具与 V02 操作纵切（P2-5）。夹具是内存模拟设备：会话/配置状态机、单调递增的配置版本、历史版本回滚、五个故障注入点（INJ-APV-1 回执丢失、2 commit 中途断连、3 身份漂移、4 版本冲突、5 慢响应）。驱动层把每个设备命令作为平台操作执行：逐回执校验设备身份（漂移即停手并登记证据）、commit 回执丢失/断连/超时一律进 unknown 并只许回读对账定案（禁止盲重试）、场景结束做清理核验（会话/暂存残留与配置基线比对）。

本包的一切行为只证明夹具与纵切逻辑，**不构成真实 APV 已验证的证据**（真实设备属 OPEN-06，P4 单独授权）。

本地验证：`npm install && npm run typecheck && npm test`。
