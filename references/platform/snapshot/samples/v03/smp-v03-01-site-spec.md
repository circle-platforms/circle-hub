# SMP-V03-01：本地测试站规格（规格文档，本阶段不实现站点）

状态：草稿，待人工核验。站点只允许本地/隔离环境部署，测试账号为虚构账号，口令字段一律用占位符表示（如 `<pwd-correct>`），不写真实口令；站点行为供 V03 验收使用，不指向任何真实产品站点（真实目标属 OPEN-07）。

## 1. 页面与流程

| 页面 | 路径（示意） | 关键元素与状态 |
| --- | --- | --- |
| 登录页 | `/login` | 用户名、口令、提交按钮；错误提示区；连续失败计数 |
| MFA 页 | `/mfa` | 6 位码输入；码由站点侧模拟器给出（页面外通道）；超时 60 秒（可注入） |
| 控制台首页 | `/home` | 登录成功标志元素；会话剩余时间显示 |
| 锁定页 | `/locked` | 连续 5 次失败后进入；显示锁定原因与解锁条件 |

## 2. 确定性行为

- 正确口令组合 → （启用 MFA 的账号）跳 MFA 页 → 码正确 → `/home`。
- 口令错误 → 停留在 `/login`，提示“凭据不正确”，失败计数 +1。
- 失败 5 次 → 账号锁定 15 分钟（站点时钟可快进，供测试）。
- MFA 码错误 3 次 → 会话作废回 `/login`；MFA 超时未输入 → 回 `/login` 并给出超时提示（与“码错误”可区分）。
- 会话 cookie：登录后设置；登出后失效；复制旧 cookie 访问 `/home` 应被重定向回 `/login`（供会话残留类场景）。

## 3. 视觉状态清单（供感知层判读的样本态）

登录页四态截图规格：空白态、凭据错误态、锁定态、MFA 等待态；每态列明可判读的视觉线索（提示条颜色/文案位置/按钮可用性），作为 V03 视觉判读的期望依据。实际截图在站点实现后（P2）采集并补入样本，不在本阶段伪造图片。

## 4. 边界

- 站点不得包含任何真实产品的商标、页面结构复制或真实口令策略细节；只模拟类别行为。
- MFA 模拟器只存在于站点侧，测试执行方经带外通道取码——与 HUM-04 的敏感通道约束对应。
