# samples：验收样本库

与 [P1 计划](../docs/p1-contract-sample-plan.md) 第 6 节的 SMP 清单对应，机器可读索引见 `registry.json`。

## 规则

- **身份与哈希**：每份样本在 `registry.json` 里以样本 ID 登记路径与 SHA-256；内容一变，哈希必变，冻结状态自动失效，需重新核验。
- **冻结条件**：样本只有附**人工核验记录**（谁、何时、结论）才算冻结。**当前全部 14 份样本已于 2026-10-10 经用户整批核验通过，状态为 `frozen`**（核验记录见 `registry.json` 各条目的 `humanVerification`）。样本文件内如有“草稿/待核验”字样，属制备当时表述，以注册表状态为准；文件内容自核验后未作任何改动（哈希可复核）。冻结后再改内容，必须走修订 + 重新核验。
- **合成与真实**：本目录只放合成样本与规格文档。真实业务样本（脱敏后）永不入库，只在注册表中登记身份、哈希与存放位置（P1 计划第 6 节）。
- **期望的归属**：样本里的“期望结果”是判断基准，属样本的一部分；被测流程不得反过来修改期望。期望有误时走样本修订 + 重新核验，不在执行现场改判。

## 目录

- `v01/` 知识问答样本（多版本、冲突与撤回、无答与相似干扰、跨 scope）。
- `v02/` APV 夹具规格与场景脚本（不连真实设备）。
- `v03/` 本地测试站规格与隔离/凭据场景（本阶段不实现站点）。
- `v04/` 用例评审样本（基本正确集、缺陷注入集与修订集）。
- `v05/` 脑图内容样本（主题树 + 合成 XMind content.json）与期望工作簿结构。
- `x/` R01–R08 横切场景卡。
