# 控制台视觉统一

依据决定 92 与任务页 `docs/hub-r4-tasks/console-visual.md` 的 Claude 审查结论。这里记录控制台自身的实现边界；阶段进度由集成者记录。

## 设定、字体与标志（第一块）

- 运行 `node tools/gen-console-style.ts`，从共享设计目录的 `tokens.json` 和原样的 `components/bundle.css` 生成 `style.generated.ts`。`node tools/gen-console-style.ts --check` 检查漂移；`style.test.ts` 对照完整源文件与生成文件，放在控制台目录以纳入常规单元测试的发现范围。运行时只导入生成模块，不读取设计文档，也没有构建或网络依赖。
- 深色是 CSS 基础值，未显式选择时跟随系统。`theme.ts` 的固定脚本在页头、样式之前执行，恢复浏览器本地的选择；界面为“跟随系统 / 浅色 / 深色”。第二块按 Claude 要求改用 `ch-seg`，放在 Sidebar 账号区或登录前面板底部，支持互斥单选与方向键。存储不可用仍可切换本页；关闭脚本时隐藏控件，CSS 继续跟随系统。不同标签页的选择通过浏览器存储事件同步。
- `html.ts` 继续按内容哈希允许固定资源：样式、主题脚本、按需加载的实时模块。主题预绘制部分只恢复设定，不订阅 SSE；第五块把固定的 DOM 交互增强拼入同一经典脚本，仅用户明确的页面选择或提交会请求原控制台路由。CSP 不允许动态样式、事件属性、任意脚本或外部资源。未认证页面也能切换主题，不读取账号和区域数据。
- 字体仅为系统字体与共享组件中 `Circle CJK` 的本地字形，中文调整为 92%，不合成粗体；旧布局中已有字重一并归到 400/500/600。表格数字与时间用等宽字体，统计大数字保留正文字体。轨道标志使用 `ch-hubmark` 和共享品牌设定；favicon 的原始字节未变。
- 模型词表值仍从生成的 `ui` 标签读取；静态文字留在控制台代码中，遵守共享规范。第六块才修改模型并生成合约，由 Claude 安排与同步分支的合并顺序；不增加静态文案登记表。

## 当前限制与后续需要

第五块已删除全部旧图表、时间轴、拓扑、颜色别名与兼容样式。`style.ts` 只包含原样生成的共享设定/组件，以及控制台的组合、状态与响应式规则。第六块已接入模型界面用语、可聚焦 Tooltip、渲染用词回归与设定对比度检查；截图和浏览器证据见任务页。完整集成、Claude 视觉审查与后续变基由集成者完成。

## 外壳与登录前页面（第二块）

登录后使用共享的三栏外壳；八区当前项、区域标识、搜索、账号与主题统一。`spaceLayout` 把既有授权投影通过 `pageLayout(content, {sidebar, inspector, detail, back})` 交给外壳，不重复读取业务数据。该包装须作为 `page()` 的直接正文传入；普通 HTML 插值不搬运布局元数据。文件夹树只在当前范围展开，最多三级。没有投影时仅显示范围链接，不补计数。第三块已删除默认页面/账号填充内容；只有页面显式提供真实概况或对象详情时才显示 Inspector，空间视图使用当前授权投影的计数。

1180px 及以下的选中详情使用 `is-detail`，返回链接由页面提供并保留筛选；760px 及以下导航收为页首一行。移动展开用原生复选开关，不依赖脚本；桌面导航在视窗中停驻，账号与主题位于底部。页头只有页面操作，主操作最右；提示可聚焦且有读屏关联。登录、改密、设置及失效页使用居中单栏和共享表单组件，没有导航投影。标准授权保留原有 redirect/form-action 和确认流程。

外壳、旧 Sidebar、旧页头与登录布局的规则已删除；旧正文/图表继续由兼容规则支撑，第三至第五块逐项迁移。第二块 Chromium 使用临时合成 Hub 核对八区两套主题及三种宽度，并用单独夹具核对详情槽与断点；这些是外壳证据，不是全部子页的视觉验收。全量子页截图、对比度与渲染用词回归在第六块完成。共享规范与摘要只读，没有向其他包提出新接口需求。

## 知识库与工作流（第三块）

`presentation.ts` 只组合共享 Section、Table、Stat、Badge、SourceBlock、Input 和 Dialog，不判断权限、不写数据。知识库、记忆、工作流列表保留现有范围与命名空间；选择通过规范网址联动 Inspector，窄屏显示同一详情，返回保留范围及文件夹分页。工作流和通用技能分组使用 ListRow，比较字段的知识/记忆集合使用 Table。来源通过既有读取边界获取可读名称与打开链接，逐字引文仍保持原文；不可读取时不猜名称。

知识首页概况来自已有可读条目与最近写入，文件夹概况来自本页节点和已授权的版本记录，工作流概况来自已读列表的数量与最近发布。其他区域没有提供概况时收起 Inspector，第四块再逐区补真实数据。当前版本以构建名或查看链接呈现；哈希、引用、工作流标识与版本信息放在关闭的“查看”详情内，核对证据仍可取得。

`table()` 统一输出可聚焦、具备名称的 `ch-table-wrap`。容器限制宽度并在内部滚动，网格列可收缩；合成浏览器核对包括 390px 下滚动到最后一列。知识批量选择仍仅开放本人已验证条目，预检为 GET，确认仍走原写入边界并逐条重查。行点击与方向键通过既有固定哈希脚本增强，行内链接和表单保持原生路径。

第三块未修改模型或生成合约。旧词表界面值按约定留到第六块统一生成；图表、全局焦点/加载/SSE 状态保存与其余六区留到第四、第五块。旧正文/图表兼容规则仍未整体删除，不能据此宣称视觉统一已经完成。

## 其余六区与第三块审查修正（第四块）

- 总览、任务、连接、记录、团队、设置与管理/搜索/结果子页改用同一套 Section、Stat、Badge、Table、Input 和 Dialog。共用 `ui.ts` 只组合共享组件，原卡片、网格、芯片、表单与对话框规则已删除。总览检查项用 Stat、`ch-parts` 和带名称/数量的图例，不再提供环形图。
- 六区概况来自当前已有授权投影：任务与未决项、本页调用、已读成员/设备/系统/环境数、凭据条目与服务事实。选中的系统和调用只从当前授权列表中解析；不存在与不可读使用相同页面。成员页保留原来元数据权限，概况不读取或统计成员私人正文。无有意义概况的操作结果页继续收起 Inspector。
- 系统、成员、调用的选择在网址中保留，表格有当前行；调用选择/返回保留原筛选和分页。任务 Inspector 显示结果、已授权来源与事实；手机通过“查看完整记录”进入 `view=record`，完整记录不会被窄屏分栏隐藏。原始主张顺序、未知状态、模型评论与生产结果的区分、全部提交与回执未改。
- 文件夹标题只保留当前名称，面包屑承载范围和上级路径；分区数量紧跟标签。知识、记忆和工作流 Inspector 操作集中在底部一行，按 ghost / danger / secondary / primary 排列。撤回、记忆停用、个人版本下架和重置成员密码先进入 Dialog；打开对话框只读，确认仍用原表单与服务边界。工作流没有直接编辑器，保留已有发布新版本能力，不添加假“编辑”。
- 已删除环形图及对应 CSS，移除旧卡片、输入、对话框与网格样式。剩余旧 SVG 图表、任务时间轴与连接拓扑的布局/颜色别名在第五块收尾；图例系列数、悬停/表格回退、统一时段、加载/焦点/实时状态保持、时间数字格式仍在第五块，完整对比度与词表用语回归在第六块。模型、合约与共享规范均未改。

## 交互与图表（第五块）

- 成员、Circle、业务系统、运行环境、凭据、版本和个人暂存行只作选择，没有按钮或写入表单。动作在所选对象的 Inspector；分享 Dialog 内的授权行选择后，在该 Dialog 的详情区提供收回分享及第二次确认。选择只从当前已授权的投影解析，未知和无权保持同一中性页面。停用、断开、吊销、收回与下架仍使用原有命令或确认写入，不增加管理员读取个人正文的能力。
- `interaction.ts` 是同一固定 SHA 允许的经典脚本。选择与筛选请求原 GET，保留原布局，图表变淡；方向键、Enter、Esc、全局搜索、Dialog 焦点圈定/恢复与背景 inert 统一处理。提交使用原 POST、Origin、CSRF、字段及 multipart 文件；禁止重复提交，按钮转圈，10 秒后提示等待。标准授权确认仍原生提交；进入授权页时加载完整原页以保留其专属 CSP。
- 增强的知识/记忆/个人发布表单带 `circle-hub-form: enhanced`，原动作成功后仅把原 303 Location 作为 JSON `{location}` 返回，再由脚本 GET；不放宽写权限、不增加写路由。这样预检的 `#Dialog` 片段不会被 Fetch 的重定向处理丢掉。原生提交仍返回 303，关闭脚本仍可完成全部流程。发生网络异常不自动重发写入，提示先核对记录；普通响应按原页面显示实际结果与证据，一次性密码/令牌不通过 GET 重放获取。
- PRG 成功提示来自会话内的一次性标记，不来自网址或客户端推测；GET 消费一次，后台刷新不消费。直接管理响应只在命令退出 0 时给出成功提示，原输出（含一次性显示的密码/令牌）持续保留。提示 3 秒隐藏，悬停或聚焦暂停；服务器错误不自动隐藏。编辑过的表单在 SSE 中保留到提交、重置或离开页面；其他模块继续刷新。切换选择会关闭旧订阅并按新模块订阅，保留滚动、展开状态和仍具备操作资格的勾选。
- `charts.ts` 从同一份已读数据产生图形、键盘/悬停提示、图例和可展开表格。单系列取区域图表色；记录趋势固定前三个工具加“其他”（余下工具及协议调用），四色顺序不变。数量比较用柱形，单个数用 Stat，组成用细分段条；任务时间轴只用一个区域色表示区间，状态写在文本中。柱宽上限、圆角、横网格、整数刻度、线宽、末端名称及最新/最大数值遵循组件规范，非有限或负数不能冒充零。
- 总览与记录的时段作用于历史统计、图表及列表。记录的工具/成员/运行筛选也用于统计，未知成员不统计其他账户的调用或私人拒收计数；切换时段重置分页。调用扫描上限 500、总览任务上限 120、时间轴最多 20 个任务、成员比较最多前 6 名均说明范围。当前知识/配置/服务快照明确标注；连接的执行器接口仅有近 24 小时响应数据，未制造 7/14/30 天历史。任务图沿用原推导步骤，派发位置按提交或任务起点定位，提示明确它不是派发完成时间；未改任务结果计算或只读 API。
- `format.ts` 统一千位、二进制大小的一位小数、分级简写时间；原时刻保留在 datetime 和完整时间提示，证据/查看入口仍可核对原值。说明性常驻文字和旧词表按审查约定留在第六块处理。本块不修改模型、合约、共享规范、同步分支或 Circle。

## 界面用语、提示与核对（第六块）

- 模型只改词表 `ui`，运行时用 `uiLabelOf` / `axisUiLabel`；静态标题、按钮、提示和错误留在控制台。中文与拉丁字母或数字之间留空格。等待外部回应的状态仍写“等待…中”，自身加载/提交/重连写“正在…”。服务端原始诊断、原文、用户名和客户端名不改写；`data-evidence` 标记这些数据，技术协议通过明确的查看入口保留。主张仍用生成的字段顺序与原字段名，列标题简为“结论”，完整主张在“查看主张”内。
- Section、字段、Stat 和图表的用法说明共用 `tooltip()`，按钮的原 `title` 由固定脚本增强；能聚焦且提供独立读屏说明，按钮名称保持动作。禁用按钮的原因由可聚焦外层承载。提示按视口/对话框边界换向；未打开时不参与溢出。事实、错误处理、安全后果和一次性密码/令牌提示保留在正文。
- `console-wording.test.ts` 渲染合成实际页面与标准连接确认，扫描可见文案和读屏属性，拒绝旧词、以“你/他”作主语及中西文缺空格；原始证据即使含旧词也逐字保留。没有静态文案登记表。`PACK_KIND` 也用于发布列表分组，不另写类型枚举。
- 按 Claude 转达的 #135 README 新规则，生成器在原样共享 bundle 后追加行辅助文字与控件状态规则。`style.generated.ts` 仍由命令生成；共享规范目录和摘要不变，后续变基接回新版。行悬停/选中辅助文字用 `text-secondary`，选中/按下控件边界用 `focus-ring`；清除重复的表格行背景。图表悬停非目标柱与加载淡化取 0.9，叠加加载时不再重复淡化，避免旧 0.45/0.5 使图形或辅助文字低于门槛。不增颜色设定。
- `contrast.ts` 只供测试/工具，从共享设定解引用并合成透明叠层，检查两主题五类底色、按钮、提示/标签、悬停/选中行、四系列及组成/加载状态；正文门槛 4.5:1，必要边界/图形 3:1。装饰分隔线、网格、标志与禁用态单列，不冒充通过样本。对比度测试不能代替视觉审查。
- 增强 POST 遵守 submitter 的原 `formaction`，包括原生 `formnovalidate`；系统试读不再误投接入路由。仍保留原 Origin、CSRF、预检、写入边界及关闭脚本路径，没有新增管理动作或放宽 CSP。

## 私人同步的视觉集成（决定 89）

同步方式、上次同步与当前冲突数使用同一套 Section、Badge、事实行和 Stat；知识和记忆共用设置，选择后交给 AppShell 的 Inspector，窄屏有独立详情和返回入口。方式及状态从合约读取，时间与容量沿用控制台统一格式；没有同步时间仍显示未知占位，不制造成功状态。管理员成员详情仅加入现有端口允许的方式和时间，不展示私人正文、标题或冲突数量。

清除先经原服务预检，再在 Dialog 里说明容量、文件夹分享、团队副本、本机副本与备份后果；必选复选项通过原生表单关联保留，确认仍用原 POST、CSRF、期望代次、状态与检查结果。重新启用同样由 Dialog 确认，仍使用所有者函数建立新代次。成功反馈从服务器会话消费一次，重新读取当前方式；重放旧回执时不会把旧清除当作新的清除。本轮不新增样式、状态轴、HTTP 权限或 MCP 工具。

变基后的来源组件也保留清除标记：旧私人路径与引用不会因新版 SourceBlock／技术信息入口重新出现；团队已持有的正文与引文仍可读。模型仅给已有清除来源标签补上新版界面用语，生成物来自合并后的模型；迁移 14、15 原样保留。截图、检查及未运行项见 kw-sync 任务页的集成一节。
