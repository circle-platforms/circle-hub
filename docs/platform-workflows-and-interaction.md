# 从实际工作检查交互

2026-10-11。核对基线为 infosec-platform 主干 `6184cdfbcb5e7b530e48773dfe4728cbb89ca6f6`。本页是前端设计检查，不代表后台业务已经实现。五条基础链是验收样例，不限定平台范围。

## 用户只面对一个应用

用户打开 Circle，说目标、附材料。会话持续保留问题、回应和工作结果。需要持续执行时关联 server 任务；普通交流不自动变成设备任务。知识和方法按授权与版本使用，用户不需要先了解架构分类或挑选业务 Agent。

结果按需展开。用例评审显示原位置、意见、依据和建议；脑图显示原节点与工作簿预览；开发显示修改差异；排障显示证据和同一执行现场。用户可以继续说话、采用意见、补条件、批准具体动作或下载结果。更换材料形成新修订，旧意见、批准和制品检查失效。

团队管理放在同一应用的授权入口中。资料、身份、方法、执行节点、运行观测、审计和恢复仍各有责任，但不成为普通用户的必经步骤。客户端与 server 可以独立部署；同一个 GitHub 产品 Project 组织两端工作。两个仓库可以保留，也可以按 client/server 分模块合仓，这项工程选择尚未定案，本轮未迁移或合并仓库。

## 当前 Demo 的实际范围

- 自然语言入口和两个可选会话样例；发送后自行推进合成处理，到具体澄清或批准点才等待人。
- 用例样例可以逐条采用/保留，形成新修订，保留旧输入并下载 Markdown 报告。新材料不会套用固定样例意见；真实 LLM 评审未接入。
- 主题树 JSON/content.json 的结构转换在浏览器中真实生成 .xlsx；核对两表、七列、行映射和单元格类型，并计算原件/产物摘要。下载保存的同一份字节。
- 业务用例编译仅展示合成方案和命令/断言缺口，不冒充可执行 Excel，不替换已冻结结构合同。完整 .xmind、多 sheet 和附件未接入。
- 其他语义结果、代码修改、设备操作、长期窗口、发布与升级是合成视图。没有正式认证、生产 server、真实公司来源、付费模型或设备连接。

脚本只在已声明输入和规则范围内建立结论；固定判断样例不是语义准确率。前端角色、localStorage、状态机和审批模拟不是生产安全与持久运行边界。
