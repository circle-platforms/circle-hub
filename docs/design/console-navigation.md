# 控制台导航

来源：所有者 2026-11-02 走查及补充（决定 130）、知识库与工作流方案（决定 131）、本阶段实施（决定 132）及所有者 2026-11-04 的决定 147。九项导航为：总览、任务、知识库、工作流、连接、记录、团队、设置、运行状况。第九项只有管理员的导航里有，其余八项不变。

| 页面 | 范围 |
| --- | --- |
| 总览 | 当前任务、结果与活动 |
| 任务 | 任务列表、请求、执行过程与完整记录 |
| 知识库 | 当前可读的团队知识、版本比较、入库待处理与产品知识来源（product 种类） |
| 工作流 | 工作流（workflow 种类，带验收）与通用技能（skill 种类，没有验收）；工作流详情上方列出验收要求 |
| 连接 | 业务系统接入（system 种类）、已连接的业务系统、自动化测试环境与 Circle 连接 |
| 记录 | 可见调用与审计记录 |
| 团队 | 管理员管理成员、权限、工作流分配与连接；成员查看本人账户 |
| 设置 | Hub 状态与系统凭据；成员的“我的 Circle”仍在此 |
| 运行状况 | 只给管理员：资源的当前值和 24 小时曲线、后台任务、崩溃和重启、按客户端、按发布、观测自身（决定 146、147） |

团队位于设置之前，运行状况位于设置之后，都没有二级菜单或数量徽标。第一个账户为管理员，其他账户仅由管理员添加。成员详情不向其他普通成员开放；列表与详情沿用当前权限，不以导航入口授予读取权。成员的导航里没有运行状况，直接打开它的地址得到和其他管理员页面一样的结果。说明性文字放在标题悬停提示中。

2026-11-09 基准核对（issue #246）：当前公开主线的管理员导航为上述九项，普通成员为八项；通用技能与工作流在同一区域内分类。某些部署版本将技能单列，需先核对该部署的来源与批准范围，不能直接据其截图增加主线入口。组件 Sidebar 的区域数量与本页保持一致。

工作流页保留 `/console/packs`，避免改变已有书签、详情链接和控制台接口路径。产品知识来源与业务系统接入分别在知识库、连接中列出；详情仍沿用原地址，面包屑按新归属显示。发布使用同一操作，标题随入口显示对应种类；不画节点图。代码、协议与目录名不改。

定时任务与机器人将来分别使用独立页面和导航入口，本次没有功能、占位或导航。个人与团队空间、同步等后续阶段按 [知识库与工作流设计](knowledge-workflows.md) 另行实施。本页记录当前改名阶段的导航；外部设计画布与接口文档由 Claude 同步。
