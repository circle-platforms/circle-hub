# 控制台导航

来源：所有者 2026-11-02 走查及补充，决定 83。七项导航调整为八项：总览、任务、知识库、任务包、连接、记录、团队、设置。

| 页面 | 范围 |
| --- | --- |
| 总览 | 当前任务、结果与活动 |
| 任务 | 任务列表、请求、执行过程与完整记录 |
| 知识库 | 当前可读的团队知识、版本比较与入库待处理 |
| 任务包 | 可用任务包、版本与发布 |
| 连接 | 业务系统、运行环境与 Circle 连接 |
| 记录 | 可见调用与审计记录 |
| 团队 | 管理员管理成员、权限、任务包分配与连接；成员查看本人账户 |
| 设置 | Hub 状态与系统凭据；成员的“我的 Circle”仍在此 |

团队位于设置之前，没有二级菜单或数量徽标。第一个账户为管理员，其他账户仅由管理员添加。成员详情不向其他普通成员开放；列表与详情沿用当前权限，不以导航入口授予读取权。说明性文字放在标题悬停提示中。

定时任务与机器人将来分别使用独立页面和导航入口，本次没有功能、占位或导航。知识库通用化另交调研方案。本页记录现行导航；外部设计画布与接口文档由 Claude 同步。
