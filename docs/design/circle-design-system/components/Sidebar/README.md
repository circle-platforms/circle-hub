# Sidebar

circle-hub 控制台的左侧导航：标志、全局搜索、管理员的九个区域入口（普通成员八个），当前区域展开出它的范围与文件夹。Circle 工作台的导航见 WorkbenchShell；区域归属以 [控制台导航](../../../console-navigation.md) 为准。

## 结构

- 顶部：轨道标志加小写字标“circle-hub”，下方是全局搜索（⌘K / Ctrl K 打开）。
- 区域入口（`ch-nav-item`）依次为：总览、任务、知识库、工作流、连接、记录、团队、设置、运行状况。运行状况只对管理员显示；成员直接访问仍按管理员页面的权限规则处理。
- 当前主线的通用技能位于工作流区域内，不是独立的顶层入口。部署扩展或其他版本的截图不能作为主线导航数量的验收基准。
- 每个入口前有一个 7px 圆点：知识库蓝、工作流紫、任务琥珀，其余用 `area-neutral`。圆点只是区域标识，不表示状态。
- 当前区域在下方展开二级项（`ch-nav-sub`）：知识库展开为“我的 / 与我共享 / 团队”，当前范围再展开文件夹树（`ch-nav-tree`），当前文件夹用区域色圆点标出。
- 底部：当前账号的头像、姓名与角色。

## 状态

| 状态 | 外观 |
| --- | --- |
| 默认 | `text-secondary` |
| 悬停 | 叠加 `surface-hover`，文字变为 `text-primary` |
| 当前 | `surface-hover` 底、`text-primary`、字重 600；`aria-current` |
| 有待处理的问题 | 右侧红字，例如“1 项告警”；只在确实需要处理时出现 |
| 数量 | 右侧等宽小字（`ch-count`），只放事实数字 |

## 规则

- 一次只展开当前区域；其他区域保持收起。
- 文件夹树最多显示三级，更深的层级在列表页里打开。
- 名称过长时单行省略，悬停显示全称。
- 导航里不放说明文字，也不放按钮。
