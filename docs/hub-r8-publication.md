# Public R8 synchronization

This branch starts at public `main` and applies the integration changes after the R7 snapshot as one signed commit.
The private history is not imported. Public-only fixes already on `main` stay, including the test shards, acceptance
runner, macOS and Linux CI jobs, dependency updates, and the case-identity and XML sandbox corrections. Draft pull
request #40 is not part of this commit and is not merged.

## Included changes

- A request keeps the authorization it read at the start; a later revocation applies to the next request.
- A submission may omit a model identity only when the observed session is the run's session. A different or missing
  session does not inherit one. Submitted bytes stay as received.
- Model-facing source text says whether the original is readable. The structured tier is unchanged.
- `get_nodes` can report the caller's own in-flight call and completed log line for the original arguments and an
  optional trace. It does not return another caller's log, the arguments, or an unsaved reply.
- A later `get_nodes` can return a short-lived process-local copy of a successful reply for the same caller, arguments,
  and trace, after rechecking the current run, root, source tier, contribution, and feeding state. Restart, expiry,
  ambiguity, and a failed recheck stay unknown. No disk copy is added.
- Template claims can be prepared in a batch from explicit category and quotation choices. The Hub still verifies each
  claim. Local quotation helpers do not accept a claim by themselves.
- Pack manifests can be regenerated by each pack's own tool. Changed published content has a new version.

## Versions

Content that changed at a version already on public `main` was given a new patch version before resigning:
`case-compile` 3.8.7, `defect-to-case` 1.6.22, `case-location` 1.4.13, `quality-board` 2.0.12, `source-read` 0.1.2,
and `mindmap-format` 1.0.3. Later private versions are carried forward: `famx` 1.7.36, `template-gap` 1.2.19,
`story-traceability` 1.0.15, and `knowledge-contribution` 1.3.10. Manifests were regenerated; digests were not edited
by hand.

## Not included

Private progress notes, task pages, and the private test-runner concurrency policy. The public unit runner keeps
the shard and concurrency policy from `main`, and lists `tools/prepare-packs.test.ts` so that new test is actually run.
The dynamic worker policy remains in the private tree. `foundation/`, `references/`, and `.github/` are unchanged.

A follow-up on this branch regenerates the two case-compile workbook samples from the current synthetic recipe,
points the mindmap-format tests at 1.0.3, and scans client skills from their tools and hooks. Hub functions that a
client script does not import stay out of that scan. The template-gap test bed asks for operating-system isolation
only where that probe succeeds, both when publishing the pack and when a run projects documents. The worker-command test names the same probe and does not start the sandbox.
