# circle-hub 文档

这是 GitHub 上 `docs/` 的目录页；文档站从 [index.md](index.md) 开始。

## 现行

- [十分钟上手](quickstart.md)：从零初始化数据根、建团队与成员、发布并分配首个工作流、连接 Circle 与首次运行。
- [改一个工作流或技能怎么做](edit-pack.md)：改工作流/技能文字或规则后的版本号升级、重算清单与摘要、内嵌依赖联动及上线步骤。
- [重置和重建](reset.md)：处理「需要重建」状态、按范围清理或初始化数据目录、保留配置重建与保留 `keys/`/`vault/` 的说明（初稿）。
- [Hub r4 架构](hub-r4-architecture.md)：给构建者的共享简报（英文）：硬规则、包归属、约定、用例评审场景、真实系统的结构、完成定义。
- [Hub r4 进度](hub-r4-progress.md)：阶段清单、记录和已定的决定。
- [设计](design/README.md)：[通用模型](design/generic-model.md)摘要与[对象标准：五要素检查单](design/object-standard.md)；英文在 [design/en](design/en/README.md)。设计的权威是 [contracts/model.json](../contracts/model.json)。
- [兼容矩阵](compatibility.md)：circle、circle-hub、circle-packs 三个仓库彼此的要求。
- [同步协议 v1](protocols/knowledge-sync-v1.md)：个人知识与记忆同步的中立规范（英文，规范性），任何客户端和服务器可照此实现；[中文概述](protocols/knowledge-sync-v1.zh-CN.md)。
