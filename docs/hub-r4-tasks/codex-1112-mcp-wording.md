# MCP 答复措辞断言同步

范围仅限 `hub/server/mcp.test.ts`、`hub/server/model-declaration-mcp.test.ts`、`tests/acceptance/34-r5-t1t3-platform-facts.test.ts`、`tests/acceptance/41-r5-t1t3-acceptance.test.ts` 和本页。

按 11-12 任务书与措辞规则同步既有 MCP 场景的正文断言。原始用例按标题逐条展示，状态和判断使用规定取值；内部位置、模式、引用和追踪信息在机器可读答复中核对。已有输入、场景和机器可读行为断言保留，未添加测试场景。

依赖 B1 提供 `start_run.record`、`submit_result.record`，并将资料未读出的原因写成面向使用者的下一步。记录引用仍由原有查询取得。

本项不运行测试，由集成分支统一执行一次 `npm test`。
