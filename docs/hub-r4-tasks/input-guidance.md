# B6：编辑页可选字段的填写说明（#234）

来源：所有者全量计划 #234/#199；基线是 #264 的分支（`fix/console-editor-foreground`，4b6cb849），因为这几行已被 #264 改动；分支 `fix/input-guidance`，PR 叠在 #264 之上，须先合 #264。

## 允许路径

- `hub/server/console/{spaces.ts,memory.ts}`、`hub/server/console-editor.test.ts`
- 本任务页、`CHANGELOG.md`

## 决定

不改接受什么、存什么，只改说明（服务端本来就把空的结构化数据读成 `{}`、空的适用条件读成 `null`，合约里两者都是 JSON 对象，适用条件可为 null）：

- 记忆正文：“纯文本保存，不执行 Markdown” 改为 “正文可使用 Markdown 标记，按原文保存，页面不渲染也不转换格式”。“不执行 Markdown”不自然，也没说是否渲染；新句没有承诺富文本预览或自动转换。
- 结构化数据：加说明“留空表示没有；填写须是 JSON 对象，例如 {"字段":"值"}”。
- 适用条件：说明加上“须是 JSON 对象”，占位符由协议值 `null` 改为“留空表示未声明”。

## 验收

- `console-editor.test.ts` 两个现有测试（渲染真实的知识编辑页和记忆编辑页）各加断言：新文字在，旧文字和 `placeholder="null"` 不在；改动前两项都失败（已实证）；整页过文案守卫。

## 不做

“正常态、提示、详情及错误态”里的其他输入说明（例如校验失败时的提示文字）。
