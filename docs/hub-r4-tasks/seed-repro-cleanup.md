# 育苗复现脚本的资源清理

用户要求：修复临时育苗复现脚本遗留的 HTTP 服务，验证成功及异常路径的清理，并评审后提交 PR。

本任务从 `hub-redesign` 建立独立分支 `codex/seed-repro-cleanup`，允许修改：

- `scripts/diagnostics/seed-lists-repro.ts`
- `scripts/diagnostics/seed-lists-repro.test.ts`
- 本任务页。

脚本使用合成的 109 文件 SVN 来源、临时 PostgreSQL 和故意拒绝文件组的生产器。资源取得后立即登记清理，依次关闭 HTTP 服务、测试世界、数据库和脚本临时目录。单项清理失败不跳过后续动作；原始执行错误与清理错误同时保留。生产器的预期拒绝报告不等于脚本异常。

入口要求 `--hub-root` 指定包含当前测试接口的源码目录；先检查所有必需文件，再按原有模块归属加载具名导出。命令直接返回 Node 的退出状态。测试检查实际进程、监听端口、临时目录和错误，而不只检查输出文字。

共享测试夹具内部尚未返回句柄的初始化故障不在本次清理保证内；强制终止仍应由调用方的明确时限约束。Circle 的后台任务策略、Hub 生产接口与共享夹具不在本次修改范围。
