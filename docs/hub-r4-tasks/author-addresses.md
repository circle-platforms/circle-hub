## 做了什么

1. **作者出处**：作者的地址是用例自己的命令行经锁定命令树解析出的地址参数，不扫描文字。计划里不在环境可达范围的地址（离开所有网段，或落在没有触发设备的网段）：
   - 是作者地址的，照留，结论里写明保留了哪些；
   - 不是的，照旧拒，拒绝写明"也不是作者原文命令里的地址"，并给出可选的改法。
   
   声明了 `bed_member: false` 的角色照旧不核；没声明用途的位置按成员核对。
2. **替换**：替换的来源可以是作者命令里的任一地址，不再只认用例索引。其余来源是计划错误（`replacement_invalid`），写明来源和解析出的作者地址，不再当成缺维护者事实的未知。
3. **逆命令**：逆命令能按几种前导参数个数解析时，计划自己写的清理只要是其中一种就成立；不是时列出全部合法写法，不再等产品包声明（同 CES：清理由作者写）。
4. **喂入说明**：读内容时附的那行改成"这份来源收进知识层的投影进行中……运行的检查只用开运行时冻结的输入，不读这一层"，下一步写"不用等它"。
