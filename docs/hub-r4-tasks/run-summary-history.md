## 现状与方向

摘要为取当前头和生产结果读取该运行的全部校验历史，单页上限 500 个完整正文；旧详情路径单独保留。先让摘要按既有索引反向逐个取候选，找到技术接受头即停止，另按运行原记录的 submission 索引寻找最后一个可读生产结果。管理弃置头保持优先，不越过被隐藏的当前技术头回退。

这是有界单次读取与早停，仍可能为寻找接受头或可读生产结果遍历拒绝/不可读候选。后续的完整run正文摘要投影、列表并发、单任务历史分页仍需推进；不以减少数量或跳过哈希/权限验证替代。

## 回归与验收

- 多历史重正文，读取当前摘要只加载所需当前头/生产候选，不加载旧无关结果；统计结果读取数量与字节，不用墙钟阈值。
- 全详情与摘要对所有者、管理员、受权部分读者结果完全一致；当前头不可读不能露出旧成功，撤权和不存在仍为中性。
- 拒绝头跨分页、旧生产候选不可读后回退、管理弃置、同时间戳写入顺序覆盖。
- 既有完整性检查仍经过 records.store.find；投影/索引不能当未经验证的最终结果。
- 类型、runs定向测试和涉及的跨包验收实际运行后记录；完整unit/acceptance和真实部署性能另行验证。
