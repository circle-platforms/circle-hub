## 和评审表不一致的两处

- **W32 写的是“主线上已找不到”，实际还有两处**：总览的数据库一行和设置页的“连接”写着“仅本机连接”。这里的“本机”指 Hub 服务器，和 W29 是同一个毛病，已改成“仅服务器本地连接”。
- **评审表只列了控制台**。W8、W11 的旧词在命令行输出和拒绝说明里也有（例如 `pack retire` 的输出、读不到包版本时的“已下架”）。同一个动作不该在网页上叫退役、在命令行里叫下架，所以一并改了；命令行里的“运行”按 W26 的约定没有动。

另有三处顺手统一的：连接确认页的“回调地址不在本机”“本机上处理……的应用”改成“这台电脑”；证书说明里的“复制到本机”改成“复制到装有客户端的电脑”；知识库页按钮提示里的“读权”改成“读取权限”。

## 为什么有两条文字用了常量

“下一步处理安排未记录”和“未写明缺少什么”在读旧结果时生成，控制台、MCP 文本和修复请求里有多处比对或显示它们。原来每处各写一遍字面量，改一处漏一处就会让比对落空。现在定义在 `contracts/src/validation.ts`（`EXIT_NOT_RECORDED`、`MISSING_NOT_RECORDED`），各处引用同一个。
