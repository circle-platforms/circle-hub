## 决定

控制台预览的标题由“确认永久删除成员”改为“预览永久删除的影响”，并在开头写明此页只预览、不删除，执行下方命令才删除且不可撤销。原来的一长段按对象分为：将清除、将转移、将保留、引用和分享的影响、账户和登录、不可撤销，每条只写一件事。分组由 `DELETION_EFFECT_GROUPS` 提供，正式标签仍来自 `uiLabelOf`。

主机命令输出的 `DELETION_EFFECT` 段落逐字不变（范围限定在控制台预览）；`member-deletion-effect.test.ts` 让两种写法互相约束：任何一边丢掉一项后果，测试就失败（已做变异检查）。“本机副本”在预览里写成“该成员客户端设备上的本地副本”，指代明确；其余页面的“本机”“Hub 所在主机”措辞属于 #232，需要先统一术语，本批不动。

不改权限、清除范围的计数、命令、状态标签、合约或生成文件；不删减任何后果。
