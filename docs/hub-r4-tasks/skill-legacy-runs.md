# A1 补充：逐运行追加迁移绑定

依据：所有者要求一次管理员命令为全部引用指定 parser@version、尚未锁定该解析器摘要的历史运行各追加绑定，原运行和结果不改。

允许修改：hub/refs/skills.ts 及测试、hub/runs/engine/evaluate.ts 及技能锁测试、hub/server/cli-admin.ts 及专门迁移命令测试、hub/refs/README.md 与本页。包解析器算法、发布文件、生成物、部署数据和真实系统不改。

旧全局声明只确定裸引用的固定迁移映射，不能替代运行级记录。命令按历史运行记录分页扫描，引用只按完整引用语法解析，不从散文抽取。每个符合条件的运行有单独的 declared action，包含原运行摘要、解析器、技能摘要、操作者、时间、迁移测试名和“迁移时点事后声明”。已有该解析器锁或绑定的不覆盖；其他技能锁保留，补绑只追加其余解析器所缺的锁。结果和主张有效条件包含原锁与追加锁，并披露声明。

命令同一映射可重复执行，已绑定的不重复，新符合条件的历史运行可补齐；另一摘要不能改绑。事务失败整批回滚，输出扫描/新增/已有计数，不输出原件正文。

合成测试：超过单页的 45 个待补绑运行（含只在提交中引用、空技能集合和只锁其他技能或已有其他技能追加声明的运行）；有锁、不相关、散文提及均保留；重复执行、后续显式续补、固定摘要复核、旧结果不变、失败整批回滚和管理员 CLI。迁移等价测试仍以原核心七文件 SHA 基线枚举全部活动 JSON 夹具与样例。

完成检查：typecheck、gen-contracts --check、引用/解析器迁移/运行复核/CLI/根查询测试 472/472（零失败、零跳过）。迁移语料为 610 份 JSON、148 个文档实例，47 个文件加 1 个生成大图。前一轮提交与词表检查 504/504；收尾专门回归 13/13。未修改包内文件及解析器算法，因此不改包版本或签名。
