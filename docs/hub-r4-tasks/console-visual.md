### 1. 由设定生成 CSS、主题切换、字体与轨道标志

1. 增加 Node 24 直接运行的确定性生成工具：读取 `tokens.json`，把颜色、阴影、字体族与字号阶梯、间距、圆角和布局尺寸转换为 CSS 自定义属性；将 `{brand-blue}` 一类引用转换为相应的 `var()`，拒绝未知引用、循环或缺项。生成文件放在控制台目录，由 `style.ts` 导出“生成设定 + 原样的 bundle.css”；运行时不依赖工作树中的设计文档。用测试对照源文件与生成结果，保证重复生成一致，不维护第二张调色板。
2. CSS 基础值为深色；未显式选主题时由 `prefers-color-scheme: light` 覆盖，显式 `data-theme="dark"` / `data-theme="light"` 优先。三档控件使用本地存储，第二块按 Claude 要求移到账号旁/登录前面板底部并改用 `ch-seg`；跟随系统时移除显式覆盖，系统变化及时生效。存储不可用或脚本关闭时仍能跟随系统，登录及首次改密页也适用。
3. 在现有固定脚本与 SHA 允许机制内实现主题初始化与事件委托；无实时模块的页面也能切换主题，不因此订阅 SSE。继续拒绝内联事件、动态 style 属性和外部资源，不增加 `unsafe-inline`、`unsafe-eval` 或外部源。测试主题样式和脚本的实际哈希与 CSP 一致。
4. 原样采用 `Circle CJK` 的 `local()` 字形、92% 调整与禁止合成粗体；控制台固定默认字号档，数字列、时间和快捷键用等宽字体，统计大数字用正文字体。轨道标志改用 `ch-hubmark` 与品牌设定，字标保持小写；`FAVICON_SVG` 与 `/console/favicon.svg` 响应保持不变。
5. 旧样式随组件迁移删除，最终整体去掉；过渡提交若仍有未迁移页面，明确列出，不能把兼容层算作完成。共享规范目录与摘要本轮只读；若组件规范不足或对比度不达标，记录具体值并交 Claude 协调共享规范及 Circle 副本，不在控制台加另一套颜色。

检查：生成一致性、主题优先级和本地存储失败、无脚本、字体与资源限制、轨道标志及 favicon 不变、CSP 哈希回归；受影响的页面和实时刷新测试。

2. 八个入口保持“总览、任务、知识库、工作流、连接、记录、团队、设置”顺序，采用区域圆点、当前项语义、账号区和搜索。当前区域的范围与文件夹树纳入同一 Sidebar，取消知识页内第二套侧栏；文件夹最多展开三级，更深处通过列表打开。保留当前基线的“全部”搜索视图，不因预览只列三个范围而删除它。

### 3. 知识库与工作流页面

1. 先迁移 `space-layout.ts`、知识库首页、文件夹、条目详情及记忆视图，再迁移工作流与通用技能列表、详情、来源和暂存预检页面。知识/记忆切换、全部/我的/与我共享/团队范围、搜索、文件夹路径和现有链接继续有效。
2. 阅读型内容使用 ListRow，需要比较字段和数字的视图使用 Table；同一对象集合不同时做列表与表格。既有原文列表保留为独立分区。标题、类型、状态、数量和时间留在主区；来源原文、分享、使用情况和版本记录组织进 Inspector，不再卡片套卡片。
3. 选择状态写入网址；桌面联动详情，窄屏直接进入同一对象的详情视图。来源用 SourceBlock，以文件名和可解析位置提供“打开原文/查看”；不得用哈希、引用编号或包版本充当标题。协议标识、原始记录与必要技术信息仍可在明确的查看入口核对，不删除核验证据。
4. 复用既有分享、收回、团队发布/撤回、记忆编辑的服务器预检和确认。批量勾选只用于已有批量能力的列表，仍由服务端校验本人、已验证等资格；不可操作时说明原因。保持个人原件保留、分享并集、记忆无需验证且不能作为结果依据、缺失与无权不可区分等规则。
5. 预览里的“分享到团队后替换旧版本”等样例不能覆盖决定 88 的实际规则；不把演示中的检查结果或使用次数复制到产品里。工作流标识和版本在必要的技术详情中可查，常规列表用可读名称。

检查：控制台目录的空间、分享、上传、暂存测试及 `console-knowledge`、`console-sharing`、`console-memory`、`console-api-write` 等受影响测试；验收 46、47、48，全部使用合成资源与临时数据。

- **连接**：系统、环境、资源、Circle 与尝试读取页面使用统一表格、详情、表单及状态；不改只读路由、凭据遮蔽和失败不重试的限制。
- **记录**：筛选、动作与来源详情统一 Table、Inspector、SourceBlock，保留读取权限和审计字段；普通页面不直接铺开内部 JSON。
- **团队**：成员、角色、发布权和容量页面统一 Table 与确认流程；只展示已授权元数据，不通过新概况或计数泄露成员私人内容。
- **设置**：账户、令牌及管理员管理入口、命令对话框、运行状态和设置步骤采用相同字段、操作与反馈；不改变管理动作或新增执行入口。

全局搜索、结果页、错误页及上述区域的子页随所属区域一起迁移，避免只统一首页。每区完成后列出覆盖的路由和剩余页面，删除对应旧样式并跑直接受影响的页面、权限、分页和管理测试。

### 5. 交互与图表

1. 统一选择与筛选网址、行悬停、Tab 焦点、↑↓ 选择、Enter 打开、Esc 退出详情或对话框，以及 ⌘K / Ctrl K 聚焦搜索。保留链接和 GET/POST 表单的无脚本路径，不让行点击吞掉链接、勾选框或表单操作。
2. Dialog 继续支持 `:target`，脚本增强焦点进入、限制与返回；遮罩点击不丢输入。会影响他人或不可撤销的操作复用真实预检/确认，按钮写动作；仅后端已有撤销能力时提供撤销，不为演示增加写路由。
3. 提交期间显示忙碌并防重复；普通列表保留布局、加载更多不丢已有行，图表刷新保留原图并变淡。超过 10 秒显示对应等待状态；成功 Toast 3 秒后关闭、悬停暂停，失败保留并给处理办法。字段错误就地显示，空状态按权限给可执行入口。
4. 调整既有 SVG 图表与统计组件：一个数用 Stat，数量比较用柱，趋势用线，组成用细分段条。单系列用 `--area-chart`；多系列稳定占用 `chart-1` 到 `chart-4`，筛选后不换色；状态图只用状态色和文字。按规范限制柱宽、圆角、线宽、端点、网格和标注，不增加图表依赖。
5. 同一份服务端数据同时渲染图、图例和“以表格查看”的表格，无脚本仍有数据；哈希允许的脚本只增强悬停、最近日期参考线与键盘提示，不从客户端猜值。近 7/14/30 天在页头统一控制本页所有统计、图表及表格；缺少该时段数据的现有页面记录限制，不虚构趋势。
6. 共用数字、容量、日期和完整时间提示的格式化；应用 120/180/240ms 动效及减少动态效果规则。SSE 更新后主题、选择、网址、滚动、已开对话框和正在输入的字段保持正确，事件委托不重复绑定。

检查：交互与图表数据一致性测试、无脚本表格和表单路径、键盘与焦点的浏览器检查、实时刷新回归、CSP 拒绝动态 style/事件处理器的安全验收。

3. **界面用语的分工**：
   - 词表里的值（状态、类型、各个轴）照旧经模型的 `ui` 字段与 `uiLabelOf` / `axisUiLabel` 读取，改词就改模型。
