## 要做到的（验收标准）

1. **设定**：
   - 由 `tokens.json` 生成控制台的 CSS 自定义属性：深色为默认；`data-theme="light"` 或系统为浅色时切换为浅色。
   - 生成物用测试钉住，与 `tokens.json` 一致。
   - `hub/server/console/style.ts` 整体换成生成的设定加 `bundle.css` 的组件样式，旧样式删除。
   - 样式仍走现有的哈希允许机制，不放宽内容安全策略。
   - 字体只用系统字体与 `Circle CJK` 的本地字形，不下载、不打包字体文件。
2. **主题切换**：页面右上角提供“跟随系统 / 浅色 / 深色”，选择保存在浏览器本地；没有脚本时跟随系统。
3. **框架与标志**：
   - 八个区域的页面全部用 AppShell 三栏与 Sidebar。登录、首次改密等未登录时出现的页面用居中的单栏，沿用同一套设定、标志和表单组件，不显示导航。
   - 根元素标明区域类（`area-knowledge`、`area-workflow`、`area-task`）。
   - 左上角是决定 82 的轨道标志加小写字标“circle-hub”，`/console/favicon.svg` 不变。
   - 窄屏规则（1180px、760px）按 README“页面结构”。
4. **组件与交互**：
   - 页面只用规范里的组件类名。
   - 同类元素按 README“同类元素的交互规则”统一：选择联动详情并写进网址；多选与批量操作条；悬停；键盘；加载；空状态；出错；会影响他人的操作先确认或预检；结果提示。
5. **图表与表格**：按 README“表格、列表与图表”以及 Chart、Stat、Table 组件改造：
   - 单系列用区域图表色，多系列按固定顺序取色；
   - 悬停提示借现有的哈希允许脚本机制实现，没有脚本时由“以表格查看”兜底；
   - 时间范围统一作用于整页；
   - 数字与时间的写法统一。
6. **用词**：
   - 按 README“文字”一节与用词对照修改模型的界面用语，经合约生成。例如“未核验”改为“待验证”，“共享给我的”改为“与我共享”，“出处”改为“来源”。
   - 页面上解释用法的文字改为悬停提示。
   - 需要新登记的用语，先在实施方案里列出。
7. **核对**：
   - 截图：两套主题，桌面 1440px 与窄屏 1024px、390px 下逐页截图，与规范的组件预览对照。结果写进本页“验证”，截图只用合成数据。
   - 对比度：用设定值检查，正文不低于 4.5:1，控件边框与图形不低于 3:1。
   - 测试：跑控制台相关的单元测试、`npm run test:docs` 与受影响的验收用例。
