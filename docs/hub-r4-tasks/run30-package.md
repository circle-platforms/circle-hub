## 评审中修复的问题

- Hub 以管理员读取导出投影可能泄露受限逐条事实，改成实际读取者并覆盖拒绝、允许和权限变化。
- 实际工作簿含两条而作业只报告其中一条，原收口可能误交付；现在每次派发都与实际生成卷的完整用例集合及 SHA 一致，早期失败派发同样校验。
- 网关新增原件字段可能绕过旧公开输出脱敏，改成显式字段白名单并逐项处理公开文本；没有新建原件归档或公开 raw/base64。
- marker 被指令强判为编写原因、展示层按文字删除等待人和改下一步，均改为保留来源事实与结构化限定。
- 升级建议一度占用错误来源 warrant，独立复审后新增 recommendation_warrant，原来源有值或缺省均保持原状。
- 三个 CLI 声明与实际参数不一致，包括输入路径误标文字及可选来源标必填，已纠正并补回归。
