# B6：生产结果页写明含义和与任务页的关系（#230 的一部分）

来源：所有者全量计划 #230/#199；基线 aded2ffd，`fix/result-page-wording`。

## 允许路径

- `hub/server/console/results.ts`、`hub/server/console-results.test.ts`
- 本任务页、`CHANGELOG.md`

## 决定

“生产结果”容易被读成生产环境里的结果，“查看运行（权威视图）”强调权威却没说它与当前页的关系。只加说明、不改正式名称：

- 结果详情页（有结果和没有结果两种）的页头提示写明：“由 Hub 在启动任务时按规则算出的结果，是工作流的产物，与生产环境无关”。
- 页内通往任务页的链接改为“查看任务完整记录（以任务页的记录为准）”：任务页的完整记录是结果以哪里为准的出处（页上原有的说明“任务的结果以本节为准”）。

## 验收

- 结果页含新的提示和新的链接文字，不含“权威视图”；该断言在改动前失败（已实证）；整页过文案守卫（`console-wording`）。

## 不做

#230 的其余部分：任务与运行在页面上轮换出现的统一，以及大量只写“查看”的入口补对象，涉及正式用语和很多页面，需要先与词表维护方协调。
