## 要做的

1. **列表先给全集**：list_task_packs 的回答先列索引，按同样的筛选列出全部任务包，每个一行（编号@版本、标题、类型），不受 offset 影响，也不因字数截断。详情照旧按预算排，放不下的按末尾说明续读。structuredContent 加 `index`。
2. **列表带上运行上下文**：列出的任务包里，凡是声明了租约或设备观察上下文的（W06 的 context），回答另给一段此刻的摘要，内容取自 Hub 自己的记录：
   - 每个声明的租约前缀：哪些包用它、已登记的前缀（只写是不是你登记的）、占用中的键（被哪个运行占着、从几点起、有没有未结束的派发作业）；可见范围同 R02 R[3]，持有人是谁不写；
   - 每台被观察过的设备：最近一次看到的构建和基础构建，带观察时刻（A05 R[3]）；不给探测原件的引用。
   
   structuredContent 加 `context`。核心不解析环境清单，名字只来自租约前缀和观察标签。
3. **读缺陷带上相关事实**：
   - 分段读取没读进的应答写进覆盖说明：请求键、路由，原因用和函数输入同一个中性说法（凭据类和扣下的应答只写"应答对你不可用"）；

5. **本地工具下载分清没有和没分配**：
   - 不存在、已下架、技能包没有安装、这个版本没有本地工具，答"没有"（404）；
