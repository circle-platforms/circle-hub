# Hub 调用观测技能

所有者要求复用 Hub 已有的调用与追踪信息，普通成员查本人、管理员查团队，技能不单独配置 API 地址或密钥。规划问答确认从 `origin/main` 开任务分支，连上 Hub 即可发现内置技能。
