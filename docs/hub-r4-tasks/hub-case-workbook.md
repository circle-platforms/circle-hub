## 附：运行器怎么读行和 G 列（集成者 2026-10-23 照运行器源码只读整理）

运行器源码只作行为参照，不抄代码。表头文字、对象名和方法名都是部署数据，下面用“运行环境配置里的某某”代称，例子全是合成的。G 写法（第 2 条）的 encode 和 decode 照这一节实现；回不来的值由生成器拒绝，不猜。

### 读单元格

- 工作簿按缓存值读，公式不求值。
- 每格用 Python 的 `str()` 变成文字：空格子是文字 `None`，整数是十进制，小数带 `.0`，布尔是 `True`/`False`。生成器只写内联字符串，所以 G 就是写进去的那段文字。
- G 空着不等于“没有参数”：运行器会传一个位置参数 `None`。没有参数的步骤写不出来，生成器拒绝。

### 选行

- 表头行之前的行不执行。
- 表头之后：
  - C 是 `1` 的行是每个用例开头先跑的初始化行；
  - A 不空的行开始一个新用例；这一行 E 空着，整个用例都跳过。
- 第一个 C 是 `0` 的行，它的 D 是说明。
- 表的最后一行当作结束标记。
- E 写的对象在运行器里找不到时，这一行被悄悄跳过。所以 Hub 的检查要保证每个 E 都是运行环境配置里登记的座位。

### 断言行（字面断言角色）

- G 不切分、不去引号：整格文字原样作期望值，逗号、引号、换行都保留，和最近一次结果比。
- “最近一次结果”是最近一个 H 空着的非断言行的返回值。所以生成器写的所有行 H、I 都空着，断言行紧跟它 after 指向的那一步；同一步后面的几条断言比的是同一个结果。
- 期望值不能是空串：空格子会变成 `None`。

### 普通行的 G

1. **带换行**：文字里有换行（LF）时，整段原样作一个位置参数，不去空白、不去引号、不认关键字。
   - 例外：运行环境配置标为“折叠换行”的方法，先去两端空白，再删掉全部 LF 和 CR（各行直接接上，没有分隔），然后照第 2 条切分。
2. **切分**：在引号外的逗号处切开。
   - 引号段从 `"` 或 `'` 开始，到下一个没有被反斜杠转义的同种引号结束；段内反斜杠只让下一个字符不算结束，反斜杠本身留在值里。
   - 没有配对的引号当普通字符。
   - 空的片段和只有空白的片段丢掉，所以连续逗号、结尾逗号不产生空参数。
3. **去引号**：每个片段去两端空白（Python 的空白，含全角空格）。整段首尾是同一种引号时，去掉这两个引号，里面再去一次两端空白。段内的反斜杠不还原。
4. **关键字**：去引号以后，片段里有 `=` 就在第一个 `=` 处分开，两边去空白。
   - 键里有半角空格：整段当位置参数；
   - 否则是关键字参数，加了引号也一样；
   - 值全是数字字符（`isdigit`）时转成整数，否则是文字；
   - 同名的键后者覆盖前者。
5. **位置参数**一律是文字，不转数字，按次序传；关键字参数跟在后面。
6. **I 列**不空时，第一个位置参数当格式串，用那个变量的值替换 `{}`。生成器不写 I。
7. **等待角色**：第一个位置参数用 `int()` 转换。

### 由此定的 encode 规则

能写成的才写，写不成的拒绝并说明是哪一条：

- 位置参数：
  - 首尾有空白、为空或含 CR 的值写不成；
  - 含逗号或以引号开头的值用整段引号包起来：值里有 `"` 就用 `'`，两种都有就写不成；
  - 以反斜杠结尾又需要加引号的值写不成；
  - 第一个 `=` 前面没有半角空格的值会被当成关键字，写不成；
  - 带换行的值只能是这一行唯一的参数，而且方法不在“折叠换行”名单里。
- 关键字参数：
  - 键只能是合约签名里允许按关键字传的参数名，重复的写不成；
  - 整数值写成没有前导零的 ASCII 数字；
  - 全是数字字符的文字值（例如 `007`）会被转成整数，写不成，非 ASCII 数字也写不成。
- 等待的时长只写 ASCII 数字。
- 每个值 encode 以后按上面的读法 decode 一遍，必须原样回来。
